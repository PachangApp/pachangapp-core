**Desarrollo en Entorno Servidor:** 

● La administración del sistema (gestión de entidades, configuración, etc) debe hacerse completamente con lenguaje de servidor.

● Consumir al menos un servicio web desde el servidor. ● Generación de informes en PDF. 

● Validación de cuentas a través de correo electrónico. ● Subir archivos al servidor. 

● Importación y exportación de datos. 

● Descarga de archivos del servidor. 

● Ficheros de Logs. 

● Integración con IA. 

**Diseño de Interfaces Web:** 

● Realiza el Prototipo y la Guía de Estilos del diseño de tu página web. 

● En la maquetación de tu proyecto utiliza: 

○ Flexbox 

○ Grid Layout 

○ Metodología BEM.  
● Utiliza elementos interactivos en la web: transiciones, animaciones, transformaciones, clip-path… 

● Desarrollo de animaciones y efectos en la web utilizando Bootstrap y/o Tailwind. 

● El diseño web debe ser totalmente Responsive en todo tipo de pantallas. 

**Desarrollo de Agentes IA para Web** 

● **Integración de IA en la aplicación web** 

El proyecto deberá integrar correctamente modelos o servicios de inteligencia artificial mediante APIs u otras herramientas específicas. 

● **Interacción con el usuario y funcionalidad del sistema** La aplicación deberá ofrecer una interfaz funcional que permita la interacción con el agente de IA y proporcione respuestas útiles al usuario. 

● **Automatización mediante workflows** 

El proyecto deberá incorporar al menos un flujo de automatización utilizando herramientas como **n8n**, que permita conectar servicios, APIs o acciones automáticas relacionadas con el funcionamiento del agente de IA.
